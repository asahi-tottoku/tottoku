# とっとく

お店などを放り込んでおける「お気に入り箱」の Web アプリです。iPhone・Android のブラウザで開いて、ホーム画面に追加して使います。

- **データはその端末の中だけ**に保存されます。サーバーには送りません(このページを置いている GitHub にも届きません)。
- 料金はかかりません。登録も要りません。
- お店のURLや名前を貼り付けると、地名とジャンルの辞書で、自分で作ったフォルダ(例:「御殿場 焼肉」「スイーツ」)に自動で振り分けます。AIは使いません。
- 機種変更やブラウザのデータ削除で消えるので、ときどき「設定 → 全部を書き出す」でバックアップしてください。

## 使い方

1. このページを開く。
2. iPhone: Safari の「共有」→「ホーム画面に追加」。Android: Chrome のメニュー →「ホーム画面に追加」(追加すると、他のアプリの「共有」に「とっとく」が出ます)。
3. Googleマップなどで「共有」→「コピー」したものを、上の欄に貼って「保存」。

## 外部とのやりとり

画面は次のものだけを読み込みます: 地図を表示するときの地図画像(OpenStreetMap)と地図の部品(cdnjs)。保存したデータを外に送ることはありません。

## データの出典

地名の辞書(`places_jp.js`)は、[Geolonia「japanese-addresses」](https://github.com/geolonia/japanese-addresses)(CC BY 4.0)を元に、市区町村ごとの中心の座標を計算して作りました。
